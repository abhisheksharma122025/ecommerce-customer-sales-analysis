# E-commerce Customer & Sales Analysis

## Project Overview
A portfolio-focused data analytics project analyzing e-commerce sales, customers, products, regions, channels and profitability.

## Tools
- SQL
- Power BI
- Excel / CSV
- Data Cleaning & Business Analysis

## Dataset
- 1,800 orders
- 700 customers
- 20 products
- 4 regions
- 4 product categories
- Website, Mobile App and Marketplace channels

## Business Questions
1. What are total sales, profit and orders?
2. Which region generates the most revenue?
3. Which category performs best?
4. Which products are top revenue generators?
5. Which customer segment creates the most value?
6. What is the average order value?
7. Which channel performs best?
8. Which customers are repeat customers?
9. What is the monthly sales trend?
10. What percentage of orders are returned or cancelled?

## SQL Skills
SELECT, WHERE, GROUP BY, ORDER BY, JOINs, aggregate functions, CASE WHEN, DATE_TRUNC, HAVING and KPI calculations.

## Suggested Power BI Dashboard
**KPIs:** Total Sales, Total Profit, Total Orders, Average Order Value, Units Sold, Non-delivered Rate.

**Charts:** Monthly Sales Trend, Sales by Region, Sales by Category, Top 10 Products, Sales by Customer Segment, Sales by Channel.

**Slicers:** Date, Region, Category, Customer Segment, Channel, Order Status.

## Workflow
Raw CSV → Data Cleaning → SQL Analysis → KPI Extraction → Power BI Dashboard → Business Insights

## Files
- `customers.csv`

- `orders.csv`

Demonstrates practical SQL analysis and business-focused dashboard requirements for a fresher Data Analyst portfolio.
